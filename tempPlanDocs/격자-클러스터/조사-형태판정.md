# 조사 — 형태를 가르는 수는 무엇이고 어디서 오나 (2026-09-04, Step 0)

> **결론 먼저:** 초판 §3.4 의 *"긴 줄이 `2R` 을 넘으면 격자"* 는 **틀렸다.**
> 격자는 **머신 한 대가 받을 수 있는 것을 하나도 안 늘린다.**
> 늘리는 것은 **포트 수와 치수**이고, 그마저 **내부 (E)에서는 치수뿐**이다.

## 1. 수의 출처 — 전수 (코드를 읽어 확인)

| 수 | 뜻 | 어디서 | 배정 결과를 보나 |
|---|---|---|---|
| `R_f` | 면 `f` 의 **깊이 목록 길이** = reach 종류 수 | `linkPlanner.clusterBeltDepthsOf` — `inserters` 의 reach 집합, 유체면은 `depthCap` 으로 잘림 | **안 본다**(주석이 그 성질을 명시) |
| 좌석 | 머신 한 대의 **한 면** 팔 정원 | `buildSpec.faceSeatArms(면 칸 수, 유체 행)` = `max(1, cells) − fluidRows`. W/E 면 `cells = h`, N/S 면 `cells = w` | 안 본다 |
| `g_max` | 벨트 한 줄이 맡을 수 있는 머신 수 | `module/link.bundleCap` → `depthBudget.planBundles` | **처리량 상한은 안 본다**(자리 사정은 그 뒤에 깎는다) |
| `a_j(m)` | 그 줄이 머신 `m` 에서 쓰는 팔 수 | `link.armsAt(group, side, inserter)` — **깊이마다 다시 센다** | 깊이 후보마다 다시 |
| 깊이 점유 | 그 깊이의 행 구간이 비었나 | `faceTable.depthClear(t, d, lo, hi)` — **칸 단위 겹침만** 본다 | — |
| 벨트 행 범위 | 그 줄이 덮는 `[최소행, 최대행]` | `linkPlanner.beltRowSpan` — 머신을 걸치면 **사이 행까지** 통으로 | — |
| 기둥 용량 | `2R` | `clusterLayout.columnTapCapacity = 2 × |reaches|` | 안 본다 |

**전부 배정 전에 답이 나온다** → 형태를 배정의 **입력**으로 둘 수 있다(되먹임 0 유지).

## 2. 면의 제약은 셋이고, 서로 다른 것을 센다

```
① 좌석   Σ_j a_j(m, f) ≤ faceSeatArms(f)              면마다.  d1 칸이 물리로 그것뿐이다
② 깊이   그 면에서 **전 구간을 덮는 줄**(관통) 수 ≤ R_f
③ 포트   Σ_j ⌈N ÷ g_j⌉                                 줄이 갈리면 그만큼 포트가 난다
```

**②가 관통 줄에만 걸리는 것이 핵심이다.** `depthClear` 는 **겹침만** 보므로,
`g_max < N` 이라 토막 난 줄들은 구간이 서로 안 겹쳐 **한 깊이를 나눠 쓴다.**
전 구간을 덮는 줄만 그 깊이를 통째로 먹는다(`beltRowSpan` 이 사이 행까지 잡는다).

> 이건 [[trunk-assignment]] §4.1 의 *"깊이를 먹는 것은 구간이 아니라 팔이 앉은 행이다"* 를
> 코드로 확인한 것이다. 같은 이유로 `g=1` 줄 여럿이 한 깊이에 산다.

## 3. gap 면의 실제 능력 — **모델보다 좁다**

| | [[trunk-blocked]] §5(모델) | 코드 |
|---|---|---|
| 가로 줄 하나가 먹이는 대수 | **2대**(위·아래) | **1대** — `tryLinkFace` 가 `machinesOn(...) !== 1` 로 거절 |
| gap 당 깊이 | **`R` 줄** | **1** — 벨트가 언제나 `LINK_LANE_DEPTH`(d2). 그룹마다 `exitDepth = 2 + nth` 로 **진출 행만** 깊어진다 |
| gap 면의 좌석 | `w` | 같음(`faceSeatArms(machine.w, 0)`) |

**모델이 코드보다 앞서 있다**(그 문서가 스스로 그렇게 선언한 상태다). 그래서 계획서 Step 1 은
새 능력이 아니라 **모델과 코드의 거리를 좁히는 일**이다.

## 4. 그래서 격자가 무엇을 바꾸나 — **세 제약에 각각 물었다**

### ① 좌석 — **안 바뀐다**

머신 한 대의 면은 어느 형태에서도 넷이고 좌석은 `h + h + w + w` 다. 기둥도 gap 을 다 열면
N/S 를 되찾아 **같은 수**가 된다. **`Σ팔 > 2h + 2w` 는 격자로도 못 넘는다** — 형태 문제가
아니라 머신 수·인서터의 문제다.

### ② 깊이 — 모듈 전체로는 늘고, **머신 하나에는 안 는다**

내부 열 채널은 폭에 따라 관통 슬롯을 이렇게 연다(전치 계산, `ℛ={1,2}` 기준):

```
띠 폭 3   벨트 행 1   좌·우가 같은 행을 집는다 → **공유 1줄**(한 줄이 두 기둥을 먹인다)
띠 폭 4   벨트 행 2   둘 다 공유              → 공유 2줄
띠 폭 5   벨트 행 3   가운데만 공유
띠 폭 6   벨트 행 4   공유 0 — 좌·우가 각자 2줄(= 2R).  더 벌릴 이유가 없다
```

```
모듈 전체 관통 슬롯 = 2R (바깥 두 면) + Σ(내부 띠가 여는 줄)   ∈ [ (C+1)R , 2RC ]
```

**그런데 클러스터는 같은 레시피 N대다** — 모든 머신이 **같은 품목**을 받아야 한다.
머신 하나에 닿는 면은 여전히 W·E(각 `R`)와 N/S gap 뿐이므로, **머신 하나가 받을 수 있는
관통 줄은 `2R` 그대로**다. 늘어난 모듈 전체 슬롯은 *다른 기둥이 다른 띠를 쓰는 것*이라
**이 제약을 못 푼다.**

> **초판이 틀린 자리가 여기다.** `L_long > 2R → 격자` 는 *모듈 전체 슬롯*과
> *머신당 슬롯*을 섞었다. 늘어나는 것은 앞이고, 막는 것은 뒤다.

### ③ 포트 — **여기만 형태가 바꾼다**

```
포트 수 = Σ_j ⌈ N ÷ reach_j ⌉        reach_j = min(g_max_j, 그 줄이 닿을 수 있는 대수)

세로(관통)  기둥 C=1        닿는 대수 = N
            격자, 공유 내부 띠  = 2·(N/C)      ← C=2 면 **N 그대로**, C≥3 이면 준다
            격자, 전용(넓은) 띠  = N/C
가로(gap)   기둥·내부 (E)    = 2  (오늘 코드는 1)
            내부 (B)         = 2C            ← 가로 띠가 기둥 여럿을 관통할 때
```

## 5. 그래서 판정

```
① Σ_j a_j(m) > 2h + 2w              → 어떤 형태로도 안 된다.  형태 문제가 아니다
② 그 안이면 100% 가동은 형태와 무관하다 (막히면 `g` 를 내려 앉힌다 — 포트가 늘 뿐)
③ 형태가 정하는 것은 **포트 수와 치수**다:
      P(C) = Σ_j ⌈N ÷ reach_j(C)⌉         치수 = ((N/C)·h + Σ가로띠) × (C·w + Σ세로띠)

   C = 1        기본.  세로 도달이 가장 크다
   C = 2        **특이점** — 공유 내부 띠의 도달이 2·(N/2) = N 이라 **포트가 하나도 안 는다.**
                높이는 절반.  폭은 띠(3~4칸) + 기둥 하나만큼 는다
   C ≥ 3        세로 도달이 2N/C 로 줄어 **포트를 팔아 형상을 산다**
   내부 (B)     가로 도달 2 → 2C.  gap 으로 밀린 품목의 포트가 준다.  **교차를 치른다**
```

**검산(관문):** `C = 1` 을 넣으면 관통 슬롯 `2R` — `columnTapCapacity = 2 × |reaches|` 와 같다. ✔

## 6. 남은 빈칸 — 다음에 채운다

```
① 유체 면의 R 감소     depthCap 이 면마다 다르므로 P(C) 의 reach 도 면마다 다르다
② 못(포트 칸)          포트가 늘면 못이 늘고, 못은 다른 줄의 구간을 자른다 → P 가 자기를 늘린다
                       (module-planning §4.6 (2)).  1차 근사에서는 무시했다
③ 치수 식              띠 폭이 배정의 부산물이라 P 와 함께 풀어야 한다.  C 는 작은 정수라
                       **열거로 충분**하다(C = 1..4 를 다 계산해 고른다)
④ 가로 띠의 실제 능력   §3 의 거리(2대 vs 1대)가 좁혀진 뒤에야 (B)의 값을 잴 수 있다
```
