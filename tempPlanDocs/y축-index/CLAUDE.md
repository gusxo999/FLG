## 이 폴더의 어휘

```
세로 채널   깊이(열) 사이의 통로. 벨트가 **세로**로 흐른다. 트랙 = 열(x)
행 채널(띠) 같은 깊이 모듈 사이의 통로. 벨트가 **가로**로 흐른다. 트랙 = 행(y)
index       좌표가 아직 없는 자리 이름. "깊이 2번 채널의 3번 트랙"
```

**둘 다 index 기계다** — 한 축의 구간을 받아 **직교하는 축의 번호**를 돌려준다.
*"x 는 index, y 는 좌표"* 는 틀린 요약이다. 맞는 요약은 아래 §1 의 표다.

## 하지 않는 것

- **세로 채널을 안 건드린다.** 계단꼴·절단선·같은 쪽 판정 그대로.
- **모듈 안쪽을 안 건드린다** — 면 배정·`FaceTable`·포트 도형은 이 계획 밖이다.
  (`FaceTable.rowIndex` 가 머신 틈을 모르는 문제는 **같은 축이지만 다른 계획**이다.)
- **DAG·격자로 안 간다.**
- **`ROW_CHANNEL_MIN`(3)을 안 바꾼다** — 수요 0이면 오늘과 같은 답이라야 한다.
