# 포트자리-순서 — 공통 컨텍스트

**한 문장:** 포트 자리를 정하는 흐름에서 **되먹임을 없애고**, 배정이 **짝**과 **순서**를
알고 정하게 한다.

세 계획으로 갈렸고 **의존이 있다**:

```
1-되먹임   되먹임 둘을 판정한다 — 어느 것이 진짜 고리인가        ← 먼저. 2·3의 전제
   │
   ├─ 2-짝    끝(N/S)을 Link 의 필드로. 되먹임 없이 채운다
   └─ 3-순서  그룹 배정 순서를 정한다 — 못을 애초에 안 만든다
```

**2 와 3 은 서로 독립**이라 순서를 바꿔도 되지만, **둘 다 1의 판정을 전제**로 한다 —
지금 흐름에 고리가 몇 개인지 모르면 *"고리를 안 늘렸다"* 를 증명할 수 없다.

## 착수 전 반드시 읽을 것

- `docs/auto-layout/module/module-planning.md` **§4.6** — 포트 위치를 정하는 것 전부
  (다섯 수 · 누가 쓰나 · 파생과 되먹임 · 어긋남 둘). **이 계획 전체가 그 절의 후속이다.**
- `docs/auto-layout/module/module-planning.md` §4.5 — 면 좌석표
- `docs/auto-layout/link/machine-link.md` — *자리가 없으면 링크를 토막낸다* (사다리 1단)
- 코드: `planner/module/linkPlanner.ts`(배정) · `planner/modulePacking.ts`(생성 3회 ·
  tidy-tree · lineEnds) · `module/link.ts`(Link · 붓기)

## 이 계획이 **하지 않는** 것

- **사다리 2·3단(gap · 다이렉트)** — 못 앉는 줄을 *더* 앉히는 능력은 이 계획 밖이다.
  여기서는 **못을 덜 만드는 것**과 **흐름을 바로잡는 것**만 한다.
- **`insertingPlanner`(트렁크·기계별 배정) 통합** — `module-planning.md` §5 의 남는
  비대칭은 그대로 둔다.
- **채널·납품 경로 알고리즘** — 포트가 어디 서는지만 바꾸고, 그 뒤는 안 건드린다.
