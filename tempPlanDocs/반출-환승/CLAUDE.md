# 반출-환승 — 상태와 고유 컨텍스트

> 상태: **승인 대기** (2026-09-07)
>
> **한 문장:** 반출 경로 하나(`host: self`)가 통로를 **자리도 안 받고 세로로 관통**한다.
> 밟는 조건은 로컬 x 두 개의 부등식이고, 밟으면 **환승**시킨다.
>
> **범위가 두 번 줄었다.** `채널-교통관리관` → `반출-환승`.
> 첫 판은 *"다리의 x 는 고를 수 없으니 겹치면 폴백"* 이었는데 **전제가 검증 안 됐고 틀렸다.**
> 둘째 판은 행 채널 전체를 도형 장부로 올리려 했는데, 잣대를 세워 재니 **위반자가
> self 반출 하나**였다(계획서 §2.7). 남은 것이 이만큼이다.

## 잣대 — 이 폴더의 판단 기준

> **통로의 칸을 쓰면 그 통로가 배급하는 자리를 받아야 한다.**
> 통로마다 배급하는 자리는 한 종류다 — 열 채널은 **세로 트랙**, 행 채널은 **가로 트랙**.
> 자리가 모자라면 **통로가 넓어진다.** 폴백은 사다리의 마지막 칸이지 해답이 아니다.

## 이 폴더의 어휘

```
반출          모듈 테두리에 갇힌 외부상자를 **전역 외곽 변**으로 내보내는 경로
self 반출     자기 열에서 N/S 로 **직진**하는 반출. 트랙을 안 먹고 **자유도도 0**이다
환승          통로의 자리를 받아서 지나가는 것. 반출에선 `host: channel` 이 그것
관통          자리를 안 받고 지나가는 것. **오늘 self 가 하는 일**
양보          `options[0]` 대신 다음 후보로 내려가는 것. **자료는 있고 시키는 코드가 없다**
```

## 착수 전 반드시 읽을 것

| 무엇 | 왜 |
|---|---|
| `planner/perimeterTrackPlanner.ts` — `selfBlocked`(≈160) · `enumerateOptions`(≈185) | **특권을 주는 조건이 거기 하나뿐**이다 — *"같은 열에 바깥쪽 형제 모듈이 있나"* |
| 같은 파일 — `TrackAssignment.options` 주석 | *"장부가 양보시킬 수 있다"* 고 적혀 있는데 **그 장부가 없다** |
| `planner/perimeterRouter.ts` — `routeWithHint` 의 `offsets` | self 는 `[0]`, channel 은 `trackX + ±maxJog`. **거래가 그 두 줄에 있다** |
| `planner/modulePacking.ts` :1330 | self 직선이 `reservedExportCells` 로 통째로 잡히는 유일한 자리 |
| `planner/deliveryRoute.ts` :281 · :450 | 납품이 그 셀을 **막힌 칸**으로 읽는 두 자리(계획 체인 · 폴백 dijkstra) |
| `planner/modulePacking.ts` :843–844 | 납품 가로 구간이 **상자 x → 로컬 0** 이라는 증거. §2.5 부등식의 한쪽 |
| `planner/channelGeometryPlanner.ts` :569 `for (let T = 1; …)` | **늘려서 푼다**가 코드로 있는 자리. 이 계획이 반출을 그리로 보낸다 |
| `planner/rowChannelPlanner.ts` 전순서 머리말 | 다리가 왜 이미 자리를 받고 있는지(§2.7) |

## 하지 않는 것

- **행 채널을 도형 장부로 올리지 않는다.** §2.7 이 필요 없다고 말한다. Step 1 의 측정이
  그걸 뒤집으면 그때 다시 연다.
- **열 채널의 폴백 도형을 안 건드린다.** `phantom` 이 폭만 잡고 도형은 dijkstra 가 정하는
  자리 — **같은 잣대의 다음 위반이지만 별개 항목**이다.
- **`margin` 출구를 안 건드린다.** 바깥이라 다툴 것이 없다.
- **`wayOuts` 의 정확도를 안 캔다.** 모듈이 답한 것을 그대로 믿는다.
- **`구간-밖-주행` A2** 는 그 폴더에 남는다.
