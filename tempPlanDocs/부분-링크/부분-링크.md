# 부분 링크 — **간선의 묶음을 양끝에서 정한다**

> 상태·읽을 것·범위는 같은 폴더의 `CLAUDE.md`.
> 아직 안 고른 갈림은 `judgements.md` (**J13**).

## §0 푸는 문제

> 나머지 줄(원료·완제품)의 `g` 는 **레인 예산**이 정한다. 링크(간선)는 **밸브만 뚫려 있고
> 주는 사람이 없어** 언제나 관통이다. 그래서 자리가 모자라면 **한 줄이 통째로 못 앉는다.**

실측이 그것을 구조적 결함으로 짚었다 (2026-09-02, `advanced-circuit`):

```
E 면 링크 입력 3줄 (copper-cable · kr-electronic-components · electronic-circuit)
면당 깊이 R = |reach 종류| = 2      ← 로드된 게임데이터에 reach 3 이 없다
링크는 반대 면으로 못 가고 · gap 은 `g = 1` 만 받는다   →  한 줄이 **반드시** 못 앉는다
처리량·머신 수와 무관하다(10/s 든 1/s 든 같다)
```

### 안 푸는 것

```
나머지 줄의 `g`      끝났다(`planBundles`)
면·깊이를 누가 정하나  `자리-배정` 의 몫 — 이 계획은 `g` 만 낸다
게임의 좌/우 레인     `벨트-레인` 의 몫
```

### 끝나면 열리는 문

```
· 링크가 자리를 잃었을 때 **통째로 실패하지 않는다** — 내줄 것이 생긴다
· `자리-배정` 의 사다리 2단이 후보 하나를 얻는다(*그 줄을 관통으로 밀어 포트를 기둥 끝으로*)
· 레인 예산이 **모듈의 모든 줄**을 보게 된다 — 지금은 링크를 `taken` 으로만 센다
```

## §1 지금 무엇이 일어나나

```
modulePacking 간선 루프
  edgeFlows(child, parent, item)        흐름을 낸다 — 여기까지는 양(rate)이다
  edgeLinkGroups(child, parent, item, config, bundle?)
                                        ↑ **아무도 안 준다** → 흐름을 한 번에 붓는다 = 관통
  seatLinkEdge(child, parent, groups)   양끝을 한꺼번에 앉힌다. 못 앉으면 그 줄이 실패
```

**받을 자리는 이미 있다** — `EdgeBundle { side, g }`. 남은 것은 *"무엇을 근거로 채우나"* 다.

## §2 어긋난 자리 — **레인 예산이 링크를 반쪽만 본다**

```ts
// laneBudget.planBundles — 오늘
taken: (face) => { /* 링크가 이미 먹은 레인을 뺀다 */ }
```

링크는 **이미 앉은 사실**(`taken`)로만 들어온다. 그래서 예산은 *"링크가 넷을 먹었으니
나머지 줄은 이만큼"* 을 셀 뿐, **링크 자신의 `g` 를 낮춰 자리를 만들 생각을 못 한다.**

## §3 할 일 — **다음 한 단계만 확정한다**

### Step 1 — **무엇을 내줄지 고른다** (확정)

`judgements.md` **J13** 의 길 셋 중 하나를 고른다. 고르는 일이지 만드는 일이 아니다.

```
전제  밸브(`EdgeBundle`)가 이미 있고 호출부가 안 준다.
      확인: `rg "edgeLinkGroups\(" src` — 인자 넷짜리 호출뿐이다
불변  안 주면 오늘 동작 그대로다 — 기전: `bundle` 이 `undefined` 면 흐름을 한 번에 붓는다
관문  *"링크가 자리를 잃으면 무엇을 내주나"* 에 답이 생긴다.
      지금은 **내줄 것이 없어서** 그 줄이 통째로 실패한다
```

**고르는 데 필요한 값이 하나 빠져 있다** — J13 의 (가)를 고르면 포트가 머신 수만큼 나는데,
그 대가(채널 폭)를 재려면 **대조 실측**이 필요하다. 외부 줄이 그렇게 떨어진 배치가
**포트 273 · 벨트 이용률 26%** 였다는 기록이 J13 에 있다.

### Step 2 — 레인 예산이 링크까지 본다 (방향)

고른 답을 `planBundles` 가 내게 한다. 그러면 링크와 나머지 줄이 **같은 예산**을 나눠 쓴다 —
오늘처럼 링크가 먼저 다 먹고 나머지가 남은 것을 받는 구조가 아니게 된다.

> **순서 주의.** Step 2 는 `modulePacking` 의 간선 루프에서만 가능하다(자식·부모 좌석표를
> 둘 다 보는 유일한 자리). 그런데 `planBundles` 는 모듈 **하나**의 함수다 — 이 어긋남을
> Step 2 착수 전에 다시 확인한다.
