# 모델 — 머신의 면을 어떻게 쓰나

> 작성 2026-10-10 · 제안이다(확인 전). 판을 돌린 수는 쓰지 않았다 — 근거는 게임의 사실 · 저장소 문서의 문장 · 적혀 있는 결정이다.
> 같은 날 먼저 쓴 판(*벨트를 어디서 끊나*)은 이 글로 갈았다.

## 0. 무엇을 모았나 — 물음 · 범위 · 가르는 기준

**물음.** 머신 한 대에 재료 여럿과 산출물이 드나들 길을, 그 머신 둘레의 칸에 어떻게 내나. 그리고 같은 머신 N 대에서 그 길들을
어떻게 잇나.

**범위.**

```
안   머신 둘레의 칸 · 그 칸에 서는 것(인서터 · 벨트 · 지하벨트 · 파이프 · 이웃 머신) ·
     같은 레시피 머신들을 세우는 방법 · 벨트가 그 무리를 떠나는 자리(출입구)
밖   무리와 무리 사이의 길(통로) · 배치 바깥으로 내보내기(반출) · 무엇을 몇 대 만드나
     — 접점은 출입구 하나다
```

`docs/auto-layout/module/trunk-concepts.md` · `trunk-assignment.md` · `trunk-blocked.md` · `face-occupancy.md` · `trunk-pipe.md` ·
`ns-face-relief.md` · `docs/auto-layout/link/machine-link.md` · `docs/analysis/flow-model.md` · `docs/용어사전.md` §A · §D ·

**가르는 기준은 하나다 — 누가 바꿀 수 있나.**

| 묶음 | 누가 바꾸나 | 절 |
|---|---|---|
| 게임이 정한 것 | 아무도 못 바꾼다 | §1 |
| 사용자가 주는 것 | 사용자(배치기는 받기만 한다) | §2 |

## 1. 못 바꾸는 것 — 게임이 정한 것

| | 사실 | 적힌 곳 |
|---|---|---|
| 머신 | 정해진 크기(가로 w × 세로 h)를 차지한다. 아이템은 **인서터를 통해서만** 드나든다. 옆면 아무 칸에서나 된다 | `entity-roles` A · `trunk-concepts` A1 |
| | 유체는 **머신이 정한 칸**에서만 드나든다. 그 칸이 어느 면을 보는지도 머신이 정한다(머신을 돌리면 같이 돈다) | `entity-roles` A · D · `trunk-pipe` §1 |
| 인서터 | 한 칸을 차지한다. **일직선으로** 팔 길이만큼 앞에서 집어 그만큼 뒤에 놓는다. 팔 길이는 종류마다 고정이다(일반 1 칸 · 긴팔 2 칸) | `entity-roles` B · `trunk-assignment` §1 |
| | 상대는 벨트 · 상자 · **다른 머신**일 수 있다 | `entity-roles` B |
| | 놓을 때 언제나 **먼 레인**에 놓는다. 집을 때는 두 레인을 다 집는다. 한 품목만 집으려면 필터 — 모든 인서터가 단다 | `belt-lane-semantics` §2 ① · ② |
| | 운반량은 유한하고 **미세한 오차가 있다** | `entity-roles` B · `belt-lane-semantics` §4 ⑷ |
| | 한 머신에서 같은 품목을 옮기는 인서터가 둘일 때 한쪽이 막히면 **다른 쪽이 전부** 옮긴다 | `flow-model` §4 (c) 뒤 절반 |
| 벨트 | 칸마다 방향이 하나이고 **레인이 둘**이다. 레인 하나가 그 벨트의 절반을 나른다. 두 레인은 따로 흐른다 | `belt-lane-semantics` §1 · §2 |
| | 옆에서 들어오는 벨트는 두 레인이 **닿은 쪽 레인 하나로** 접힌다. 한 칸에 두 벨트가 양옆에서 들어오면 각자 자기 쪽 레인에 실린다 | 같은 문서 §3 |
| | 한 벨트의 끝이 다른 벨트를 향하면 칸을 안 나눠 써도 이어진다. 벨트의 끝 칸도 어딘가로 흘려 넣는다 | `entity-roles` C · `belt-terminus` |
| | 벨트 위에서는 **먼저(상류에서) 놓고 집는 인서터가 먼저**다 | `flow-model` §4 (a) |
| 지하벨트 | 입구와 출구 사이는 땅 위가 빈다. 인서터는 **입구 · 출구 칸에서는** 집고 놓고, 그 사이에서는 못 한다. 레인은 그대로 간다. 사거리에 한도가 있다. **종류가 다르면 서로 간섭하지 않는다** | `entity-roles` C · `trunk-blocked` §4 |
| | 입구에 옆에서 벨트가 붙으면 한 레인만 들어간다 | `belt-lane-semantics` §4 |
| 파이프 | 방향이 없다. 닿으면 한 관망이 된다 — 다른 유체끼리는 닿기만 해도 섞인다. 인서터 없이 유체 칸에 **직접** 닿아야 한다. 지하파이프는 종류와 무관하게 서로 간섭한다 | `entity-roles` D · `trunk-pipe` §1 |
| 그 밖 | 분배기 · 로더 · 상자가 게임에 있다(쓰느냐는 §3) | `entity-roles` |

## 2. 사용자가 주는 것 — 배치기는 받기만 한다

| 사용자가 고르는 것 | 거기서 나오는 수 |
|---|---|
| 무엇을 초당 몇 개 만드나 | 머신 수 · **머신 한 대의 몫**(그 머신이 초당 받고 내는 양) |
| 어느 재료까지 직접 만드나 | 재료가 자식 머신에게서 오나, 밖에서 오나 |
| 머신 종류 | 크기 · 속도 · 유체 칸의 자리 |
| 벨트 종류 | **벨트 한 줄이 나르는 양** — 인서터가 싣는 줄은 그 벨트의 레인 하나(절반)다 |
| 인서터 종류 | 인서터 하나의 운반량(사용자가 정한 값 그대로 쓴다) · **팔 길이가 몇 가지인가**(긴팔을 골랐나) |
| 지하벨트 · 지하파이프 종류 | 사거리 · 종류 수. 위저드에서 반드시 고른다 |

수치(15 · 9 · 5 같은)는 전부 여기서 나오는 **예시 값**이다. 조건이 아니다.

## 4. 거기서 따라 나오는 것 — 머신 한 대가 가진 것

§1 과 §2 만으로 정해지는 수다. 머신을 어떻게 세우든 이것을 넘지 못한다.

```
      2 2 2
      1 1 1
  2 1 ███ 1 2 3      1  머신에 붙은 칸 — 인서터가 서는 자리
  2 1 ███ 1 2 3      2  일반 인서터(팔 한 칸)가 집는 칸
  2 1 ███ 1 2 3      3  긴팔 인서터(팔 두 칸)가 집는 칸   (오른쪽에만 그렸다)
      1 1 1
      2 2 2
```

| 가진 것 | 얼마 | 까닭 |
|---|---|---|
| 인서터 자리 | 둘레 `2h + 2w` 칸에서 유체 칸을 뺀 것(3×3 이면 열둘) | 인서터는 머신에 붙어 서서 일직선으로만 옮긴다 |
| 품목 하나에 드는 인서터 | `올림(그 머신의 몫 ÷ 인서터 운반량)` — 벨트 줄마다 올린다 | 인서터 운반량이 유한하다 |
| 인서터 하나의 집는 칸 | **하나로 정해진다** — 선 칸에서 팔 길이만큼 | 그래서 한 면에서 벨트가 설 수 있는 거리는 팔 길이의 가짓수만큼이다 |
| 집는 칸 하나가 실을 수 있는 품목 | 벨트 한 칸에 레인 둘 → **둘까지**(받는 쪽은 필터로 가른다) | 레인이 둘이고 따로 흐른다 |

이 넷은 `격자-클러스터` §0 이 이미 적은 말과 같다 — *머신을 어떻게 늘어놓아도 머신 한 대가 받을 수 있는 것은 하나도 안 는다.*
머신을 세우는 방법이 바꾸는 것은 **이 가운데 얼마가 열려 있나**와 **이웃 머신의 집는 칸과 한 줄로 서나**다.

## 5. 바꿀 수 있는 것 — 배치기가 고르는 것

묶으면 넷이다. 칸마다 *지금 고른 것* 과 *다른 선택* 을 적는다. 다른 선택에 이미 이름이 붙어 있으면 그 이름을 쓴다.

### 가. 머신을 어떻게 세우나

```
붙여 세운다(지금)          사이를 벌린다                 면이 트이게 늘어놓는다
   ███                       ███                          ███    ███
   ███                       ███
   ███                       ═══  가로 벨트                ███    ███
   ███                       ███
위 · 아래 면이 막힌다        위 · 아래 면이 열린다           네 면이 다 열린다
벨트 하나가 여러 대를        가로 벨트는 위 · 아래 두 대     벨트 하나가 여러 대를 곧게
곧게 지난다                  까지 닿는다                    지나지 못한다
```

| 고르는 것 | 지금 | 다른 선택 |
|---|---|---|
| 붙이나 벌리나 | 세로 한 줄로 붙인다(`ColumnCluster`). 인서터 자리가 넘칠 때만 그 자리를 벌리고, 틈의 가로 벨트는 **한 대만** 맡는다 | 두 대마다 벌려 가로 벨트 하나가 위 · 아래 두 대를 맡는다(`trunk-blocked` §5 — 모델은 있다) · 면이 트이게 늘어놓는다(`GridCluster` — 없다) |
| 몇 줄로 | 한 줄 | 기둥 여럿(`격자-클러스터` Step 3 — 방향만 있다) |
| 어느 쪽으로 돌리나 | 유체가 있으면 유체 칸이 옆면을 보게 돌린다. 아이템만이면 안 돌린다 | 아이템 머신도 돌린다(`known-limits` §3) |
| 누구와 맞닿나 | 자식 무리와 부모 무리를 **따로 짓고** 벨트로 잇는다 | 자식 머신과 부모 머신을 맞닿게 세운다(바로 옮기기 — 없다) |

### 나. 품목마다 길을 어디에 내나

길 하나 = (인서터가 서는 칸, 그 인서터가 집거나 놓는 칸).

| 고르는 것 | 지금 | 다른 선택 |
|---|---|---|
| 어느 면 | 산출물은 부모 쪽 옆면, 재료는 자식 쪽 옆면(선호다). 넘치면 — 모듈 자기 줄(원료 · 완제품)은 반대편 면이나 틈으로, 자식이 대는 줄은 틈으로만 | 자식이 대는 줄도 반대편 면으로(`부분-링크` — 꺼져 있다) |
| 어느 인서터(팔 길이) | 인서터 수가 적게 드는 쪽 · 가까운 쪽부터. 인서터는 머신에 붙어 선다 | 긴팔이 한 칸 떨어져 서는 조합(`trunk-assignment` §1) |
| 그 면의 몇째 칸 | 포트 쪽 끝부터 붙여 앉고, 못 쓰는 칸은 거른다 | — |
| 유체 | 머신이 정한 칸. 고를 것이 없다 | — |

### 다. 집는 칸에 무엇을 세우고 어떻게 잇나

| 고르는 것 | 지금 | 다른 선택 |
|---|---|---|
| 집는 칸에 서는 것 | 한 품목을 싣는 벨트 | 좌우 레인에 품목 하나씩 싣는 벨트(`MixedItemBelt` — 같은 품목 두 줄만, 꺼져 있다) · 지하벨트의 입구나 출구([유도.md](유도.md) §4 ②-나 · ②-다 — 안 들였다) · 이웃 머신(없다) |
| 벨트의 방향 | 옆면에서는 **면을 따라** 세로로(`ClusterBelt`), 틈에서는 가로로 | **면에서 수직으로** 뽑는다(`ParallelBelt` — 없다) · 꺾이는 길(`trunk-concepts` A6 — 없다) |
| 한 줄이 몇 대를 지나나 | 양이 허락하는 만큼. 세로줄이 모자라면 우선순위 낮은 줄부터 한 대씩(모듈 자기 줄만). 두 줄을 쓰는 머신의 몫 때문에 다시 끊는다(자식이 대는 줄) | 자식이 대는 줄도 자리가 모자라면 한 대씩(`부분-링크` — 꺼져 있다) |
| 어느 쪽으로 흐르나 | 형제 순번이 준 끝(선호) · 두 줄을 쓰는 머신이 맨 끝에 서게(조건) | [../방향/](../방향/CLAUDE.md) 에서 따로 본다 |
| 무엇이 땅속으로 가나 | 남의 출입구 행을 비켜 갈 때 · 틈의 출구가 옆면을 건널 때 | 남의 **벨트** 밑으로(위의 지하벨트 칸) |

### 라. 벨트가 무리를 어디로 떠나나

| 고르는 것 | 지금 |
|---|---|
| 출입구의 자리 | 기둥 전체를 지나는 줄은 기둥 끝, 일부만 지나는 줄은 면 바깥 옆. 통로는 이 자리를 *정해진 것* 으로 받는다 |

## 6. 모델 한 장

**대상** — 머신 한 대의 둘레: 인서터가 서는 칸과, 거기서 팔 길이만큼 떨어진 집는 칸(§4 의 그림).

**단위** — 길 하나 = (인서터가 서는 칸, 집거나 놓는 칸). 머신은 품목마다 길이 §4 의 수만큼 있어야 한다. 유체는 머신이 정한 칸에
파이프가 닿는다.

**정하는 것 — 넷**

| | 무엇을 | 그것이 정하는 것 |
|---|---|---|
| 가 | 머신을 어떻게 세우나 | 어느 면이 열리나 · 이웃 머신의 집는 칸과 한 줄로 서나 |
| 나 | 품목마다 길을 어디에 내나 | 집는 칸의 자리 |
| 다 | 집는 칸에 무엇을 세우고 어떻게 잇나 | 벨트가 몇 줄인가 · 줄마다 어느 머신을 지나나 · 어느 머신이 두 줄을 쓰나 |
| 라 | 벨트가 무리를 어디로 떠나나 | 통로가 받는 자리 |

위에서 아래로 좁아진다 — 가 가 나 의 후보를, 나 가 다 의 후보를 정한다. *벨트를 어디서 끊나* 는 다 의 한 칸이다.

**지켜야 하는 것**

1. 받는 머신이 100% 로 돈다 — 품목마다 길이 모자라지 않고, 그 길의 집는 칸에 그 품목이 필요한 만큼 온다(벨트 한 줄에 실린 양이
   그 벨트가 나르는 양을 안 넘는다 · 두 줄을 쓰는 머신의 몫이 계획대로 갈린다).
2. 칸 하나에 하나만 선다. 품목이 다른 벨트끼리 흘러들지 않고, 유체가 다른 파이프끼리 닿지 않는다.
3. 벨트는 출입구에서 모든 집는 칸까지 끊기지 않는다.
4. 한 레인에 두 재료를 싣지 않는다. 계산이 정확히 맞아야만 도는 구조를 만들지 않는다.

**치르는 값** — 출입구 수(벨트 줄 수이고 통로의 폭이 된다) · 모듈의 크기 · 지하벨트. 차례는 §3 의 첫 줄이다.

**지금 코드는 이 넷에서 한 점을 골라 서 있다** — 가: 세로 한 줄로 붙인다 · 나: 좌 · 우 면 · 다: 한 칸에 한 품목, 면을 따라 곧게 ·
라: 기둥 끝이나 옆.

### 재료가 많아지면 — 이 장으로 읽기

지금 고른 점에서 머신 한 대에 열린 면은 좌 · 우 둘이다. 여러 대를 곧게 지나는 벨트가 설 수 있는 세로줄은 **면 둘 × 팔 길이의
가짓수**이고, 인서터 자리는 `2h` 다. 품목 수(받는 재료 + 산출물)가 그 세로줄 수를 넘으면 가 · 나 · 다 가운데 어딘가를 바꿔야 한다.
바꿀 수 있는 것은 아래가 전부이고 — **벨트를 더 끊는 것은 그 가운데 한 줄이다.**

| | 수단 | 무엇이 느나 | 값 | 지금 |
|---|---|---|---|---|
| 가 | 머신 사이를 벌린다 | 위 · 아래 면이 열린다 — 인서터 자리 `+2w`, 가로 벨트 | 모듈이 높아진다 | 가로 벨트가 한 대만 맡는다 |
| 가 | 면이 트이게 늘어놓는다 | 네 면이 다 열리고 벨트를 수직으로 뽑는다 | 벨트 줄 수 = 머신 × 품목 | 없다 |
| 가 | 기둥을 여럿 세운다 | 모양(낮아진다). 머신 한 대가 받는 것은 안 늘고 안쪽 기둥은 면이 준다 | 출입구 | 계획(방향) |
| 가 | 자식과 부모를 맞닿게 세운다 | 그 품목은 벨트가 없어진다 | 두 무리가 한데 엮인다 | 없다 |
| 나 | 긴팔 인서터 | 세로줄이 면마다 하나 는다 | 사용자가 골라야 한다 | 된다 |
| 나 | 반대편 면 | 그 면의 세로줄(산출물과 나눠 쓴다) | 벨트가 무리를 돌아간다 | 모듈 자기 줄만 |
| 다 | 한 대씩 방문한다 | 세로줄 하나를 여러 품목이 칸으로 나눠 쓴다 | 출입구 = 머신 × 품목 | 모듈 자기 줄만 |
| 다 | 좌우 레인에 품목 하나씩 | 세로줄 하나에 품목 둘, 여러 대 방문은 그대로 | 두 벨트가 마주 만나는 자리 · 필터 | 같은 품목 두 줄만 · 꺼짐 |
| 다 | 남의 칸은 땅속으로 지난다 | 세로줄 하나에 품목 둘 | 지하벨트(둘 다 그러려면 두 종류) | 안 들였다 |

어느 수단을 어떤 차례로 쓸지는 이 장이 정하지 않는다 — §3 의 차례(받는 머신 100% → 머신 · 벨트를 안 늘린다)와 *공짜일 때만* 이
이미 정한 부분이 있고, 나머지는 정할 일이다.

## 8. 모르는 것 · 문서끼리 어긋난 곳

**게임에서 확인 안 된 것**

- 한 머신의 인서터 둘이 둘 다 안 막혔을 때 **반반** 옮기나(가정 — `flow-model` §4 (c) 앞 절반). 두 줄을 쓰는 머신의 조건 전체가 이 위에 서 있다.
- 지하벨트 **출구** 칸에 옆에서 벨트가 붙으면 어떻게 되나(`belt-lane-semantics` §4).
- 인서터가 한 레인만 집게 하는 설정이 블루프린트로 나가나(같은 문서 §7).

**정한 적이 없는 것**

- 재료가 세로줄보다 많을 때 위 표의 수단을 **어떤 차례로** 쓰나. 자식이 대는 줄은 오늘 아무 수단도 저절로 안 쓴다(J14 — [judgements.md](judgements.md), 옛 `부분-링크`).
- 머신 한 대가 **세 줄**을 쓸 때의 몫.
- 받는 재료 하나가 산출물 벨트의 빈 레인을 타도 되나([유도.md](유도.md) §3 전제 2).
- 벨트 양쪽에 머신이 서면(틈 · 기둥 사이) 싣는 쪽도 두 레인을 다 쓴다 — 그 형태를 따진 글이 없다.
- 멀리 있는 벨트에서 가까운 벨트로 인서터가 옮겨 주는 형태. `용어사전` §ColumnCluster 가 *"벨트끼리 잇는 걸 허용하면 상한이 사라진다"* 고만 적었다.
- 자식과 부모를 맞닿게 세우는 것은 *따로 짓고 벨트로 잇는다* 와 부딪힌다 — 그 모델이 없다.

**문서와 문서 · 문서와 코드가 다른 말을 하는 곳**

- `trunk-blocked` §5 끝의 *폐기* 문단은 *붙여 세운 기둥에서 면 길이가 3 이면 세로줄 하나에 두 품목을 못 올린다* 고 적고,
  `trunk-assignment` §5 는 *품목 셋이 선다 — 코드가 그렇게 놓는다* 고 적는다. 뒤의 것이 가리키는 시험
  (`module/build.test.ts` *"아이템 3줄이 유체 면을 비켜 W 3칸에 앉는다"*)은 있다. 앞 문단이 낡았는지는 판정하지 않았다.
- 안쪽 세로줄의 출입구가 바깥 세로줄을 건너는 자리 — `trunk-assignment` §3 은 *언제나 땅속으로 비켜 줄 수 있다* 고 하고,
  커밋된 `link/policy/delivery.groupSharedFaces` 는 *두 재료가 같은 자리에서 끊어야 한다* 를 전제한다. 판정하지 않았다.

**이 장이 하지 않은 것** — 어떻게 한 번 지나가며 짓나(규칙). 이 장은 *무엇을 정하고 무엇을 지켜야 하나* 까지다.
