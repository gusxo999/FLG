# 1-지하벨트 — 작업 컨텍스트

> 상태: **조사 완료 · 착수 가능.** 코드 변경 0.
> 부모 §9 가 **(A′) 구간 사슬**로 확정됐다(D10) — 지하는 그 뼈대의 **인자**다.

**계획서는 [1-지하벨트.md](1-지하벨트.md), 부모는 [트렁크벨트-경로모델](../트렁크벨트-경로모델.md).**

```
1-지하벨트    ← 여기. 독점당한 통로를 **남이 건널 수 있게** 한다
2-격자배치     통로를 늘려 **독점 자체를 깬다**
```

## 조사에서 뒤집힌 것 둘 — **읽기 전에**

**① 지하는 자유도를 크게 늘리지 않는다.** 지하 구간 위에서는 인서터가 못 먹인다(몸통이
땅속). 그래서 트렁크가 **탭하는 구간은 반드시 지상**이고, 부모 §3 정리(밀착 기둥 → 통로
독점이 유일해)는 **지하로 안 깨진다.** 지하가 바꾸는 것은 독점의 **배타성**뿐이다.

**② 만들 것이 거의 없다.** 간섭 규칙·자료형·입구 방향 제약·방출이 **전부 구현돼 있다**
(계획서 §1). 없는 것은 *"모듈 안쪽 트렁크 계획이 그것을 부를 자리"* 하나다.

> 처음에 나는 *"두 층 장부를 새로 만들자"* 고 적었다. **이미 있는 것을 다시 만들자는
> 말이었다.** 코드를 안 읽고 사용자에게 게임 규칙을 물어본 결과다.

## 확인된 게임 규칙 (2026-08-13, 코드로 검증)

```
간섭:  같은 blockGroup ∧ 같은 axis ∧ 같은 line  →  구간이 strict disjoint
       그 외(축 다름 · line 다름 · 티어 다름)   →  전부 무해
방향:  점프는 지상 도착 방향과 같은 방향만 (입구 칸에서 꺾을 수 없다)
탭:    지하 구간 위에서는 인서터가 못 먹인다
```

**blockGroup 은 벨트 프로토타입 자체다** — 티어를 여럿 고르면 지하 자유도가 그만큼 는다.

## 하지 않는 것

- **혼자 착수하지 않는다** — 지하는 (A′) 뼈대의 **인자**다. 뼈대(구간 사슬)가 먼저 서야 얹힌다.
- **지하파이프** · **`containerRouting` 수정** · **채널 층** — 계획서 §8.

## 함정

**★ 코드를 읽기 전에 게임 규칙을 묻지 않는다.** 이 폴더의 조사에서 물어본 넷
(간섭 규칙 · 수직 교차 · 티어 독립 · 입구 방향)이 **넷 다 코드에 있었다.**
`docs/README.md` 의 판정 순서가 그것이다 — **프로젝트 문서 → 코드 → 그다음 Factorio 문서.**

**★ "탭 지점은 지상" 을 잊지 않는다.** 납품 경로에는 없던 제약이다. 납품은 끝점만
중요하지만 **트렁크는 중간이 곧 일하는 자리**다(계획서 §4-4).
