배치 격자 도면

모듈·채널·반출이 격자의 어디에 서고, 그 자리가 어떤 식으로 계산되며, 우리가 그것을 무엇이라 부르는지. 아래 도면의 수치는 서로 맞물린 실제 값이다 — 트랙 수가 폭을 만들고, 폭이 colX 를 만든다.

축척 1칸 = 16px
평면도 2 · 모듈 9
갱신 2026-09-08

평면도

가장 작은 완전한 경우. 포트 · 다리 · 트랙이 다 보이도록 한 납품을 네 토막으로 펼쳐 두었다.

깊이가 하나 더 붙고 한 열에 모듈이 셋 쌓인 경우. 열 채널이 둘이 되고 colX 가 열·채널·열·채널로 이어 붙는다. 루트 R 의 세로 자리는 자식 셋의 스팬 중앙에서 나온다.

무엇이 그려져 있나

자리는 이 순서로 계산된다

행 채널 높이
높이 = channelWidthFromTracks(트랙 수, 3) = max(3, 트랙 수 + 2)

폭 역전 — 고르는 값이 아니라 수요의 결과다. 도면의 사이 행 채널은 트랙 2개라 max(3, 4) = 4. 이 값이 사슬의 맨 앞이라, 이때는 절대 좌표가 하나도 없다.

topY
topY[다음] = topY[이전] + heightOf(이전) + gapBelow(이전) topY[B] = 0 + 6 + 4 = 10

그 모듈 extent 의 위쪽 변이 앉을 절대 y. 열마다 순번 0부터 누적합이고, 더하는 것은 모듈 높이와 행 채널 높이뿐 — 상수가 없다.

absPortY
absPortY(id, anchorY) = anchorY + topY[id] − ext.y

로컬 행을 절대 행으로 바꾸는 함수. − ext.y 가 붙는 이유는 topY 가 extent 의 위쪽 변을 말하는데 anchor.y 는 로컬 원점 기준이라서다.

trackCount
통합 장부가 도형을 배정한다 → 쓴 트랙 수가 나온다 좌표계 = (추상 트랙 열 × 절대 행)

절대 y 는 이미 있는데 절대 x 는 아직 없는 한순간이다. 그래서 세로축은 실제 값을 쓰고 가로축은 번호를 쓴다 — 취향이 아니라 그때 쓸 수 있는 유일한 좌표계다.

colX
channelWidth(d) = max(3, trackCount + 2) = max(3, 3+2) = 5 colX[d] = colX[d−1] + colWidth[d−1] + channelWidth(d) colX[1] = 0 + 8 + 5 = 13

colWidth[d] 는 그 열에서 가장 넓은 모듈의 폭이다. 모듈 B 는 6칸이지만 열은 8칸 — 그래서 B 의 동쪽에 빈 자리가 남는다.

절대 x
shiftModule(m, colX[depth] − ext.x, topY − ext.y) trackX = channelStartX(d) + 1 + track = 8 + 1 + 2 = 11

모듈을 로컬에서 절대로 옮긴다. 이 식이 모든 모듈의 extent 왼쪽 변을 colX[depth] 에 정렬시키고, 그래서 같은 깊이 안에서 절대 x = colX[depth] + 로컬 x 가 성립한다.

낱말

격자와 좌표

행 / 열
행은 y 값 하나가 가리키는 가로 줄, 열은 x 값 하나가 가리키는 세로 줄.
모듈-로컬 좌표
모듈을 혼자 지을 때 쓴 좌표. 원점이 그 모듈 안이라 옆 모듈과 비교 불가.
절대 좌표
모듈을 옮겨 붙인 조립 도면 전체의 좌표. 절대 행 = 그 y.

모듈과 열

depth
트리에서 루트로부터 몇 단계인가. 0 = 최종 산출물, 깊을수록 원료 쪽.
moduleExtent
그 모듈의 모든 칸(머신 + 벨트·인서터·상자)을 감싸는 최소 사각형. 기둥보다 크다.
colWidth[d]
깊이 d 열의 폭 = 그 열에서 가장 넓은 모듈의 ext.w.

통로

트랙
통로가 배급하는 주행선 한 줄. 열 채널은 세로줄, 행 채널은 가로줄.
cap · capCol
cap = 트랙 번호 상한. capCol = cap+1 은 가상 열 — 실제 칸이 아니라 “동쪽 벽”을 뜻하는 자리표다.
trackX
트랙 번호를 절대 x 로 푼 값. channelStartX(d) + 1 + track.

반출

exitEdge
어느 바깥 변으로 나가나 — N·S·W·E. 축을 이 값이 정한다.
exitMode
주행선을 어디서 얻나 — direct(직진) / channel(환승).
entry
환승의 진입점. y = 가로 진입이 달릴 절대 행, wall = 어느 벽으로 들어오나.
seatRow / seatCol
상자가 최종적으로 앉을 마진 행·열. rawBbox 에서 2칸 바깥.
