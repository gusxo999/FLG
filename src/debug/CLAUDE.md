# debug/ — 콘솔 조작 API (`window.flg`)

화면을 **텍스트로 누르고 읽는** 채널이다. 설계·규약은
[docs/debug/ai-console.md](../../docs/debug/ai-console.md).

**명령을 추가하기 전에 그 문서 §2(세 방식 판정)를 읽는다** — 버튼이 스토어 액션 하나인지,
컴포넌트 안에 로직이 있는지, 리스너가 React 밖에 붙어 있는지에 따라 정직한 구현이 갈린다.
잘못 고르면 명령이 화면과 다른 것을 누르면서 성공한 척한다.

**명령 목록은 문서에 안 적는다** — `flg.help()` 가 단일 출처다([[변수명사전]] 의 범위 규칙).
새 명령에는 `label`(화면 라벨)·`usage`·`available`(못 쓸 때의 **처방**)을 붙인다.
